# Phase 1 Backend Setup

This backend starts with a minimal FastAPI scaffold so we can grow the project in phases without refactoring the entrypoint later.

## Current scope
- App factory and versioned API router
- Shared settings loaded from environment variables
- Health endpoint for container and deployment checks
- CORS defaults for local frontend development

## Build phases
1. Project setup
2. Database design
3. Authentication
4. User management
5. Meeting upload
6. File storage
7. Background processing
8. Speech-to-text
9. Transcript processing
10. AI meeting analysis
11. Task extraction
12. Reminder system
13. Dashboard APIs
14. Notifications
15. LangGraph agents
16. Security
17. Testing
18. Deployment
